# 🤖 AI Persona Chatbot

A personal AI persona chatbot built with Flask and OpenAI GPT-4o-mini, featuring a modern dark blue UI with code highlighting, thinking animations, and markdown rendering.

---

## ✨ Features

- 🎨 Dark blue cyberpunk UI
- 💬 Real-time chat with typing indicator
- 🧠 Thinking steps animation (Analysing → Thinking → Processing → Almost there)
- 💻 Code blocks with syntax highlighting & copy button
- 📝 Markdown rendering (bold, italic, inline code)
- 😄 Emoji & emotion-aware AI responses
- 📱 Responsive design (mobile friendly)
- ⚡ Enter key to send messages
- 🖼️ Custom avatar images

---

## 🚀 Local Setup

### Step 1 — Clone or create project folder

```bash
mkdir my-persona
cd my-persona
```

### Step 2 — Create virtual environment

```bash
python -m venv venv
```

### Step 3 — Activate virtual environment

```bash
# Windows
venv\Scripts\activate

```

### Step 4 — Install dependencies

```bash
pip install flask openai python-dotenv gunicorn
```

### Step 5 — Create `.env` file

```
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxx
```

### Step 6 — Run the app

```bash
python app.py
```

Visit → **http://localhost:5000** ✅

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **AI:** OpenAI GPT-4o-mini
- **Frontend:** HTML, CSS, Bootstrap 5, Vanilla JS
- **Fonts:** Orbitron, Rajdhani (Google Fonts)
- **Deployment:** Render
